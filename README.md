# 想法炼炉 · 发散引擎

一个帮你在 AI 时代「把想法炸开」的单页工具。你丢一个模糊念头进来，它用多种**思维动作**把想法长出一棵树：多视角、SCAMPER、第一性原理、反向、问题重述、思维卡（复用 think3 的概念）、跨界对撞、双想法杂交。数据全部存在你浏览器本地，不上云。

> 定位：和 `think3`（先写三行 · 思考训练）互补。think3 让你**自己写**、工具查漏；本工具让 **AI 替你生成**、你做策展。一个管「想透」，一个管「炸开」。

## 运行方式

### 方式 A：本地代理（推荐，无 CORS、密钥不进前端）
```bash
cd idea-forge
UPSTREAM=https://api.openai.com/v1 API_KEY=sk-xxx node server.js
# 然后浏览器打开 http://localhost:8787
```
工具里的设置：Base URL 填 `http://localhost:8787`，API Key 留空（代理会注入）。

### 方式 B：纯静态直连
直接用浏览器打开 `index.html` 即可。设置里填：
- Base URL：`https://api.openai.com/v1`（或任意 OpenAI 兼容地址，如本地 Ollama）
- API Key：你的密钥
- 模型：`gpt-4o-mini` 或你想要的

> 注意：浏览器直连 `api.openai.com` 可能被 CORS 拦截。若报跨域错误，改用方式 A，或把 Base URL 指向一个允许浏览器跨域的兼容端点 / 代理。

## 怎么用
1. 上方输入框写一句话念头，按「开始发散」(或 ⌘/Ctrl+Enter)。
2. 想法树出现后，**点选任意节点**高亮它。
3. 底部工具栏选一个思维动作，作用到选中的节点，AI 流式长出子分支。
4. 每个分支可「采纳 ✓ / 丢弃 ✕」；分支还能继续被展开，形成树。
5. 左侧「想法库」保存所有历史念头，可随时回去继续、或拿两个做「双想法杂交」。

## 文件
- `index.html` — 界面与样式（单页）
- `app.js` — 发散引擎、想法树、流式调用、本地存储
- `server.js` — 可选本地代理（解决 CORS + 隐藏密钥）
