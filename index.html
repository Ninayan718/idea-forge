API 设置

默认魔搭 ModelScope API-Inference：国内可达、OpenAI 兼容、chat 接口已开放浏览器跨域、有免费额度。本地代理(server.js)模式填 http://localhost:8787，密钥由代理保管。
去 modelscope.cn → 右上角头像 → Access Token（https://modelscope.cn/my/myaccesstoken）复制 token 粘贴。前置：账号须先绑定阿里云并完成实名认证，否则会 401（Please bind your Alibaba Cloud account）。Token 格式 ms-xxxx，只粘 token 本体，不要带 Bearer 前缀或前后空格。用本地代理(server.js)时可留空。
填魔搭上的模型 Model-Id，如 Qwen/Qwen2.5-72B-Instruct；额度紧张可换更小的 Qwen/Qwen2.5-7B-Instruct
